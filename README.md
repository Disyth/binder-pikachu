# Binder Pikachu

Binder virtuel de ma collection de cartes Pokémon Pikachu (FR, sinon EN).

En ligne : https://disyth.github.io/binder-pikachu/

- Données des cartes, images et prix : [TCGdex](https://tcgdex.dev) (et quelques scans pokemontcg.io).
- La collection est enregistrée dans le navigateur de chacun (localStorage), jamais dans ce dépôt.
- Partage en lecture seule : bouton « Partager », la collection est encodée dans le lien.
